# Steyning South Walk sat nav

Training sat nav for a Steyning delivery round. Open the live page on a phone and tap Start sat nav.

Map data © OpenStreetMap contributors (ODbL).

## Ashurst round (test)

`/ashurst/` is a second sat nav built from the sorting frame (shelves 1 to 14, left to right). Pins marked "best guess" were placed on the nearest likely building and need checking on the ground.
